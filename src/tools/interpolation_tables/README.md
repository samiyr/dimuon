# Interpolation tables

The interpolation tables generated by the `dimuon` driver in kernel mode and the `dimuon_interpolation_tables.py` controller is essentially a large matrix, written as an unraveled 1D list. The conversion back to a matrix that can then be "dotted" (i.e. multiplied) by matrices of PDF and FF values to get a cross section value, is done by `convolution.py`. 

The function `import_gridfile` in `common.py` imports a gridfile and slices it into a list of interpolation grids by resonance type (with `split_by_resonance=False`, it returns the whole file as a single grid instead). This list can then be fed into `convolve_df` in `convolution.py`, alongside functions defining the PDF and FF. More specifically: `convolve_df` takes three callables, mirroring the functions provided by LHAPDF, that are used to get the $\alpha_s$ more the PDF (`pdf_alphasQ2`, which mirrors the `alphasQ2` member function of LHAPDF), and the PDF and FF values (`pdf_xfxQ2` and `ff_xfxQ2s`). The output of `convolve_df` is a dataframe, where the rows correspond to cross section values at the kinematical points the interpolation tables contain.

The functionality in `pineappl_conversion.py` can be used to convert these ad-hoc interpolation grid files into the [PineAPPL](https://zenodo.org/badge/latestdoi/248306479) grid format. The conversion itself is handled by `convert_grid_to_pineappl`. The helper function `dump_grid_directory_to_pineappl` converts all grid files in a folder to the `PineAPPL` format, one file at a time with `convert_gridfile_to_pineappl`, and it is what `pineappl_conversion.py` calls. The `PineAPPL` grids of each grid file are written to a subdirectory of the output directory named after the grid file (without the `.csv.gz` suffix), as one `<resonance>.pineappl.lz4` file per resonance. `pineappl_conversion.py` takes in two required arguments, `--inputdir` and `--outputdir`, which are the input and output directories used by `dump_grid_directory_to_pineappl`. There is also an optional `--pattern` argument, which is used by `glob` to determine which files in the `--inputdir` should be converted. The default pattern is `*.csv.gz`.

A simple example of how to use the PineAPPL grids is given in `pineappl_example.py`. In particular, it shows how the intermediate resonances are combined into a single cross section and how to use the KKKS08 and BKK05 fragmentation functions (for which the light-quark flavors need to be halved).
